# Architecture Decision Records

This directory stores Architecture Decision Records (ADRs) for RELI.

Rules:

1. Every architecture-affecting change must reference an ADR.
2. ADR identifiers are zero-padded and increasing, for example 0001, 0002.
3. ADR status must be one of Proposed, Accepted, Superseded, or Rejected.
4. Superseding an ADR must reference both old and new ADR IDs.

Template location:

- docs/adr/template.md
